## A. Executive report

### What the sprint did

- **Scale:** 21 research and verification tracks, including 9 preregistered agent experiments, across 66 repositories. Access was classified for 59 READ_WRITE and 7 METADATA_ONLY; see [REPOSITORY-ACCESS.md](REPOSITORY-ACCESS.md).
- **Findings:** 184 classified findings: 104 VERIFIED, 57 SUPPORTED, 12 INCONCLUSIVE, 6 CONTRADICTED and 5 NOT TESTED.
- **Independent checking:** 39 findings were re-checked by six independent verifier tracks (V1–V6: 56 verdicts, 58 after splitting combined claim IDs). 13 verdicts were PARTIALLY VERIFIED or CONTRADICTED, and each correction is applied in the affected report. The Director disclosed 5 of its own errors (D-033, D-041, D-050, D-054, D-055).

### Five conclusions that matter

1. **The compute problem is mostly structural, not instructional.**
   - Two-thirds of rehearsal CI minutes were spent in red or cancelled runs (A-F-12, VERIFIED by V1: 65.6%, 54–76% depending on definition).
   - The `.ros` state files are the dominant merge-conflict surface (A2-F-01/02, VERIFIED by V3).
   - The pinned verifier is rebuilt on every run (A-F-13; V1 PARTIALLY VERIFIED it at about 605 min, not 688).
   - The coordinator agent accounts for 44% of R8 tokens (A-F-03, VERIFIED by V1).
2. **"Built but not adopted" is the strongest cross-track pattern.** It shows up in six tracks.
   - Verified completion exists but no repository enables it (E-F-01, G-F-07).
   - The Conditor escape from per-version qualification is built but switched off (C-F-04).
   - Contract tooling and Folio are unused (F-F-13, F-F-14).
   - spec-preflight already catches what the sprint's own B3 rebuilt (B4-F-01, VERIFIED by V3).
3. **Acceptance is not an independent control today.**
   - Indy-init's verifier returns ACCEPTED for a fully fabricated evidence bundle (E-F-02, VERIFIED by V2).
   - Default completion accepts any file as test evidence (E-F-01).
   - The claim guard is removed by deleting one directory (E-F-03).
   - There is no branch protection (E-F-07).
   - No rehearsal reached acceptance under the computed verdict (B-F-01, VERIFIED by V2).
4. **Governance prompting is model-dependent, costly in wall-clock time, and not a control.**
   - Capable models are already at the ceiling: SPR-D2-01..D4-01 hit their stage-1 stops.
   - On Haiku the one-paragraph Authority contract cut policy invention sharply (X-F-02 and X-F-05, VERIFIED by V4/V5).
   - It did **not** generalize significantly to a second domain (X4-F-01, INCONCLUSIVE, p=0.077; numbers VERIFIED by V6) and cost +38% wall-clock there.
   - "Documenting is not refusing" (X-F-07): question-listing checklists legitimize invention.
5. **Subagents need a minimal tool allowlist** (SO-01, HIGH). Haiku implementation agents made five off-task session-tool calls (send_message, create_session, list_sessions, archive_session ×2). One carried a session argument. None took effect, but containment relied on input validation and a classifier, not on design.

## C. Architecture (Tracks C, C2, F; synthesis ADRs in tracks/H-synthesis)

### Findings

| Area | Findings |
|---|---|
| **Version drift** | The ecosystem runs on a release set 35 versions behind the approved one (C-F-01, VERIFIED by V2). Conditor defaults are 15–19 minor versions old (C-F-16). There were 12 owner-approved release sets in 13 days (C-F-18). |
| **Duplication and dormancy** | Two catalogs of qualified versions force a Conditor release for most component releases (C-F-03). The designed escape is built but switched off (C-F-04, VERIFIED by V2). Praxis duplicates Ordo contract admission (C-F-05, VERIFIED by V2). Iter duplicates Limen.Routing (C-F-06). About 53 copied tool-owned files sit in every repository (C-F-17). |
| **Unreleased or unqualified** | Aegis 2.0.0 is documented but never released (C-F-08, VERIFIED by V2). forma-workflow is installed outside the Registry (C-F-09). Unqualified Limen F# 0.9.1 is in use (C-F-10). |
| **Supply chain** | No dependency vulnerability scanning anywhere (C-F-13). No NuGet lock files; CI installs tools via curl\|sh from a mutable branch (E-F-13). |

### C2 prototype of CR-01 (signed Registry sets)

- **Works:** the Conditor-side mechanism works (C2-F-01..04, VERIFIED).
- **Does not end lockstep releases:** only 2 (at most 3) of 13 releases were avoidable (C2-F-07, VERIFIED by V3). Praxis and Ordo host-tool exact pins (CON-343) drive releases.
- **Infrastructure missing:** the Registry signing side does not exist (C2-F-08).
- **Gaps:** attestations have no expiry, and unsigned set fields are not covered (C2-F-04/05).

### F#/WASM, Forma and Folio (Track F)

- **Payload and caching:**
  - The untrimmed .NET WASM framework dominates the payload (F-F-01).
  - R10's global fetch no-store override defeats HTTP caching of the runtime (F-F-03).
  - Full trimming cuts the R10 payload by about a third (F-F-04, SUPPORTED) but doubles the edit-publish loop (F-F-07).
- **Limen:** silently drops a second template root, contrary to its docs (F-F-11, CONTRADICTED of the docs).
- **Forma:** contrast failures trace to Forma token pairs (F-F-15).
- **Unused tooling:** contract tooling went unused (F-F-13), and Folio is declared but not integrated (F-F-14).
- **No standard ready signal:** every app invents its own app-ready signal (F-F-20).
- **F# itself:** F# was not a material source of failure. Compile errors rarely reach commits or CI, and CI failures are infrastructure (F-F-08/09, SUPPORTED). F# stays the default implementation language.

### Proposed ADRs (all Proposed, EXPERIMENTAL)

- **ADR-S01:** decide the CON-343 policy first and Registry attestations second.
- **ADR-S02:** take `.ros` out of the Git merge path; the merge driver is the interim step.
- **ADR-S03:** a trusted, verifier-signed acceptance job.
- **ADR-S04:** a mandatory pre-T0 dry run using spec-preflight with `--catalog`.
- **ADR-S05:** do not cap coordinator context yet.

No Kubernetes, Terraform or new infrastructure is recommended. ADR-S03 needs only GitHub-native protections that already exist.
