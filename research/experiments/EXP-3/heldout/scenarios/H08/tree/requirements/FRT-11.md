# FRT-11: Driver manifests

Requirements: FRT-11-R1, FRT-11-R2. Owner: Last Mile Operations.

## FRT-11-R1

The driver manifest marks each parcel that needs a signature on delivery under the signature decision in force.

## FRT-11-R2

After a failed delivery attempt the manifest schedules the next attempt, or, once the attempts in force are used up,
returns the shipment to the depot with the date until which the depot holds it.

Acceptance criteria: each statement above holds; existing behaviour is unchanged except as these requirements say.
